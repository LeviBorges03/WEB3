# Biblioteca

A aplicação de Biblioteca inclui as seguintes funcionalidades principais no catálogo:

## Funcionalidades

### Favoritos
Os usuários podem favoritar livros na página de Detalhes da Obra. As escolhas são armazenadas localmente no navegador utilizando `localStorage`, sob a chave `bibliotecaFavoritos`.

Para adicionar ou remover um livro da sua lista de favoritos, clique no botão "Adicionar aos Favoritos" / "Remover dos Favoritos".

### Pesquisa
Na página inicial do catálogo, existe uma barra de pesquisa que permite filtrar os livros por título ou autor. Ao digitar na barra, a exibição dos livros é filtrada automaticamente, apresentando apenas os livros que correspondem à pesquisa e ocultando os restantes.
