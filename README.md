# WEB3

## Funcionalidades
- **Sistema de Pesquisa**: Permite filtrar livros em tempo real por título, autor e gênero.
- **Sistema de Favoritos**: Permite favoritar livros, gravando as informações no `localStorage` do navegador para serem mantidas sem necessidade de login. Exibe os favoritos com uma estrela `⭐` no catálogo.

## Desenvolvimento
- Este é um projeto ASP.NET MVC rodando sem Entity Framework, utilizando dados dinâmicos da Controller e mantendo estado via client-side scripts.
