# WEB3 - Documentação Estática do Projeto Biblioteca

Esta pasta contém as versões estáticas (HTML/CSS/JS puros) das visões (Views) principais do sistema Biblioteca (Livro e Autor). Elas servem para demonstração rápida do design de UI/UX, fluxos de frontend e prototipação do Sistema de Biblioteca Digital.

## Funcionalidades do Frontend (UI/UX)

- **Favoritos Funcionais (localStorage):** O protótipo na subpasta `Livro/index.html` inclui um botão "Adicionar aos Favoritos" que reflete e persiste o estado no `localStorage` do navegador, demonstrando de maneira isolada a lógica integrada posteriormente no sistema .NET.
- **Layout Responsivo:** Desenvolvido com CSS moderno (Grid e Flexbox) para se adaptar perfeitamente a dispositivos móveis, tablets e telas amplas.
- **Visualização SPA:** Assim como o projeto ASP.NET principal, elementos como cores sólidas e sinopses dinâmicas buscam replicar os dados transacionados no local storage, fornecendo um fluxo de navegação orgânico e suave sem carregamentos pesados ou requisições complexas.
