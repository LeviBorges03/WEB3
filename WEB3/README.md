# WEB3 - Protótipo da Interface

Este diretório contém a representação estática (protótipo) da interface de usuário da aplicação Biblioteca. Ele é construído puramente com HTML, CSS e JavaScript sem depender do backend em ASP.NET Core.

## Propósito

* **Documentação Viva:** Serve para demonstrar o design, comportamento do CSS e scripts da interface (como o grid expansivo de livros, e botões).
* **Base para Views:** O código desenvolvido aqui serve de template para as Views Razor do diretório principal.

**Nota:** Sempre que atualizar lógicas de interface no projeto principal (como sistemas de busca ou layout dos favoritos), lembre-se de refletir essas mudanças nestes arquivos estáticos para manter a consistência da documentação de UI.
