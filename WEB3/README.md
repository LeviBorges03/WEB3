# Protótipo Frontend Estático - Biblioteca (WEB3) 🖥️

Bem-vindo à pasta `WEB3`. Este diretório contém os arquivos de representação estática (protótipos puramente em HTML, CSS e JS) para a interface de usuário da Biblioteca, operando de forma isolada do backend ASP.NET Core.

A finalidade deste espaço é facilitar a prototipagem e o design da interface, garantindo uma representação visual clara de todos os componentes da aplicação (como as páginas do Livro e do Autor).

## Como Executar o Protótipo Localmente

Para testar a interface de forma rápida sem iniciar todo o ambiente do .NET, você pode servir estes arquivos localmente usando o Python.

1. Navegue até o diretório `WEB3`:
   ```bash
   cd WEB3
   ```
2. Inicie o servidor embutido do Python:
   ```bash
   python3 -m http.server 8000
   ```
3. Acesse `http://localhost:8000` no seu navegador para visualizar as páginas.

Nota: Lembre-se de manter os estilos e as estruturas CSS alinhados entre a implementação em C# no diretório raiz e o protótipo desta pasta.
