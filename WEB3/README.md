# WEB3 - Biblioteca Mockups Estáticos

Este diretório contém os protótipos de front-end estáticos para o projeto Biblioteca Digital. Eles são escritos puramente em HTML, CSS e JavaScript Vanilla para demonstrar os fluxos de interface, estilo (UI) e experiência do usuário (UX) antes de serem integrados ao ecossistema ASP.NET Core MVC (C#).

## Páginas Disponíveis

- **/Livro/index.html**: Página de detalhes do livro e sistema de adição de livros ao localStorage (Sistema de Favoritos).
- **/Autor/index.html**: Página descritiva de perfil do autor.

## Funcionalidades Demonstradas

- **Estilos Fluidos e Animados**: Implementação de botões "pill-shaped" com transições CSS fluídas.
- **Integração SPA Local**: Uso do `localStorage` para simular o tráfego de dados do livro selecionado e salvamento do status de "Favorito" do livro sem a necessidade de um backend operante.

Os arquivos finais integrados e completos de produção residem nas pastas `/Views`, `/Controllers` e `/wwwroot` do diretório raiz. Considere manter esses mockups atualizados conforme o estilo principal avança.
