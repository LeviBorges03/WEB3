# WEB3 - Protótipo Estático de Interface

A pasta `WEB3/` deste repositório não faz parte da aplicação de fato. É um espaço de **prototipação estática e isolada** focado puramente em Frontend (HTML, CSS e JS vanilla).

## Objetivo

Esta pasta abriga os primeiros visuais propostos para a aplicação de Biblioteca, permitindo que a equipe modifique, discuta e teste componentes UI/UX de forma rápida e fluida e sem depender das Views ou roteamento do ASP.NET Core MVC.

## Como Usar

Basta abrir qualquer arquivo `.html` (por exemplo, `WEB3/Autor/index.html` ou `WEB3/Livro/index.html`) diretamente no seu navegador. Os estilos e scripts lá contidos rodam integralmente sem a necessidade de servidor.

**Importante**: Qualquer alteração de design permanente (novos CSS, animações ou componentes, como por exemplo os botões de Pesquisa e Favorito) feitos aqui deverão ser posteriormente migrados e integrados para o projeto raiz ASP.NET nas pastas `Views/` e `wwwroot/`. O objetivo principal é servir como referência de layout e mock up.
