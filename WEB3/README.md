# WEB3 Prototipação 🎨

Este diretório contém uma representação puramente estática e isolada (HTML, CSS e JS, sem ASP.NET Core) da interface da Biblioteca.

Ele serve como um ambiente de prototipação para testes de UI/UX antes da integração com o .NET. Qualquer alteração de design, estilo (CSS) ou comportamento base em JS deve ser primeiramente validada aqui e, em seguida, espelhada no projeto principal.

Para executar, basta abrir os arquivos `.html` no navegador.
