# WEB3

## Protótipo Estático de Frontend
Contém a base HTML/CSS/JS para o projeto principal, permitindo testar a usabilidade e visuais da biblioteca antes da integração com o C# (ASP.NET).

### Novas Funcionalidades:
- Barra de pesquisa integrada para filtrar obras em tempo real.
- Sistema de Favoritos mockado via localStorage que exibe os itens favorecidos de maneira visual.
