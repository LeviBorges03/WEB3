# WEB3 - Protótipo UI Estático

Este diretório contém uma representação puramente estática e isolada (HTML, CSS e JavaScript sem ASP.NET Core) do protótipo de UI.

## Objetivos
- Facilitar a prototipagem rápida e visualização das interfaces (`Livro` e `Autor`).
- Manter uma referência consistente do design visual antes de integrá-lo com as views do MVC (`.cshtml`).

## Manutenção
Qualquer modificação estrutural, de estilização ou adição de novas lógicas interativas nestes arquivos estáticos (como o sistema de favoritos via `localStorage`) deve ser espelhada na raiz do projeto (no respectivo arquivo `.cshtml` ou `.css`) para manter a consistência da aplicação.
