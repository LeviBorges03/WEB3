# Protótipos Estáticos (WEB3)

Esta pasta abriga os protótipos puros em HTML, CSS e JavaScript da nossa aplicação, sendo totalmente independente do framework .NET Core.

## Finalidade
Seu objetivo é facilitar a prototipagem de UI/UX de forma rápida sem a necessidade de instanciar a infraestrutura de backend. Quaisquer adições de design, transições, botões de ação (como os sistemas de favoritos e filtragens via JavaScript) são testadas aqui.

A pasta deve sempre ser mantida síncrona com o código final (Views) que está sendo desenvolvido. Caso você deseje modificar um estilo ou script client-side, altere e experimente aqui primeiro, e depois repita a mudança nas páginas do servidor.

## Notas
- A navegação aqui também usa `localStorage` localmente para simular o comportamento da aplicação final.
