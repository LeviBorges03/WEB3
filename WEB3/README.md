# WEB3

## Funcionalidades

### Favoritos
Os usuários podem favoritar livros na página de Detalhes da Obra. As escolhas são armazenadas localmente no navegador utilizando `localStorage`, sob a chave `bibliotecaFavoritos`.

Para adicionar ou remover um livro da sua lista de favoritos, clique no botão "Adicionar aos Favoritos" / "Remover dos Favoritos".
