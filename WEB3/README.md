# Protótipo Estático (WEB3)

Este diretório contém uma versão estática e isolada da interface do usuário (HTML, CSS, JS puro), sem nenhuma dependência do ASP.NET Core.

Seu principal propósito é para o **design e a prototipagem** de layout, permitindo que a equipe de front-end ou design valide e trabalhe no CSS/HTML sem precisar rodar ou compilar o back-end C#.

Ao fazer modificações de estilo, lembre-se de manter consistência entre esta pasta e a raiz do projeto MVC.
